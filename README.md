# IT本番変更 Go/No-Go Checker

OpsFrame Labが提供する、本番変更前の準備状況を整理する無料チェックツールです。

## 公開サイト

GitHub Pagesの公開後、この欄にURLを記載します。

## 主な機能

- 12問に `Yes / 要確認 / No` で回答
- `GO / CONDITIONAL GO / NO-GO` の3段階で判定
- 判定理由と未確認・未対応項目を表示
- Safe Change Kit（500円）への案内
- ログイン、Cookie、個人情報収集、外部APIなし
- スマートフォン／PC、キーボード操作に対応

## 技術構成

HTML、CSS、JavaScriptだけで動作する静的サイトです。回答内容はサーバへ送信されず、ブラウザにも保存されません。

## 判定について

このツールは、一般的な変更管理の観点を整理するための補助ツールです。変更の安全性や成功を保証するものではありません。実際の変更可否は、所属組織の規程および責任者の判断に従ってください。

## ローカル確認

`index.html` をブラウザで開くと動作します。
